# 用量仪表条（Usage HUD）— Hermes 桌面插件

给你的 Hermes 桌面版底栏加一条实时用量仪表：**轮数步数、输出速度、token 总计、缓存命中率、上下文占用圆环**，鼠标悬停还能看到十几项细节。

一个文件，不用编译，不用装依赖。

```
11轮 153步 | 53 token/s | 总计 2.4M | 输入 238K 输出 4K · 缓存 90% | 上下文 24%◔
```

---

## 它解决什么问题

Hermes 桌面版默认底栏不显示任何用量。你花了多少 token、缓存命中了多少、上下文还剩多少、现在跑多快 —— 全得自己猜。

装了这个插件，这些数字就长在底栏上，**而且是实时的**，回复一边生成一边跳。

别的用量插件（比如 tokstat）只显示 4 个数字。这个显示 **18 个后台字段里的 12 个**，包括其他插件都没有的「轮数 / 步数」。

---

## 装法

### 方法一：手动放文件（最快）

1. 把 `desktop/plugin.js` 复制到：

   ```
   %LOCALAPPDATA%\hermes\desktop-plugins\usage-hud\plugin.js
   ```

   （`%LOCALAPPDATA%` 一般是 `C:\Users\你的用户名\AppData\Local`。
   如果你用命名 profile，路径是 `%LOCALAPPDATA%\hermes\profiles\<profile名>\desktop-plugins\usage-hud\plugin.js`）

2. **文件夹名必须叫 `usage-hud`**，跟插件 id 一致，否则加载不了

3. 桌面版里按 `Ctrl+K`（Mac 是 `Cmd+K`），搜「重新加载桌面插件」

### 方法二：从 Git 仓库装

桌面版 → 设置 → 插件 → 从仓库安装，填这个仓库地址。

## 显示的内容

### 底栏（常驻）

| 位置 | 内容 | 说明 |
|---|---|---|
| 1 | `11 轮 153 步` | 本会话发了几轮话、调了几次工具 |
| 2 | `53 token/s` | 最近十来次请求的平均生成速度 |
| 3 | `总计 2.4M` | 本会话总消耗（含缓存读） |
| 4 | `输入 238K 输出 4K · 缓存 90%` | 未命中缓存的输入 / 生成 / 缓存命中率 |
| 5 | `◔ 上下文 24%` | 上下文窗口占用，带圆环 |

### 悬停（13 条）

```
模型：wb-deepseek-v4.1-flash
轮数/步数：11 轮 153 步
输出速度：53 token/s（最近十来次请求的平均）
平均一次请求：8.3 秒（含等首字的时间）
本会话输出（生成）：4,408 token
本会话输入（未命中缓存的部分）：238,030 token
本会话缓存读（复用的历史，按缓存价计费）：2,170,240 token
本会话合计（入 + 出 + 缓存读）：2,412,678 token
缓存命中：90%（越高越省钱、越快）
上下文占用：24%（243K / 1.0M）
其中思考 token：1,250
正在跑的子代理：3 个
上下文压缩过：2 次
```

## 想改样式

打开 `desktop/plugin.js`，找 `function Hud()`：

- **改顺序 / 删某一项**：调 `children: [...]` 数组里的顺序，删掉不要的那段
- **改颜色**：用的是 Hermes 自己的变量 `--ui-text-quaternary`（淡字）、`--ui-accent`（圆环）、`--ui-stroke-secondary`（竖线分隔符），跟着主题走
- **改圆环大小**：`function Ring()` 里的 `r = 5`
- **想要更多位数**：`fmtTokens()` 控制 K/M/B 缩写

存盘就热重载，不用重启。

## 注意

1. **只读，不写任何东西。** 它只从后台读数据，不改配置、不碰密钥、不发网络请求。
2. **会往插件数据目录写两个诊断文件**（`last-readout.json`、`usage-keys.json`），方便你排查「为什么不显示」。位置是 `%APPDATA%\Hermes\plugin-files\data\usage-hud\`。不想要可以删掉 `writeDiag()` 的调用。
3. **轮数/步数靠数会话记录。** 所以切到很早的老会话时，要等它数完才显示数字，中间会短暂显示 `—`。
4. **`--ui-*` 这类变量名是 Hermes 内部实现。** 上游改版可能改名，届时对应那条美化会失效（不会报错，只是不好看），跟着改一下变量名即可。
5. **需要 Hermes 桌面版。** CLI 和纯网关没有状态栏，装了看不到东西。
